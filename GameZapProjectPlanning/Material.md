## **What Is It?**
- A description of the shaders that are in effect for the mesh
## **What Does It Do?**
- Creates bind groups
- Updates buffers
- Updates textures
## **What Does it Store?**
- All current attachments
	- Attachments are either textures or buffers
- An ID
- Paths to its corresponding shaders
- Bind group layouts
- Bind groups and buffers
